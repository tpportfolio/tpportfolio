# Project rules

Rules set by the owner. They apply to every change in this repository.

1. **Two languages, always.** Every change to content, navigation or UI text must be made in Spanish and in English, saying the same thing with the same facts, names, numbers and dates. This includes `alt`, `title`, `aria-label` and placeholders. Spanish is rioplatense, first person, with voseo.
2. **Keep agent mode in sync.** Every change must also be reflected in `/agents.md` and `/agents.txt`. They are generated by `lib/agents.ts` from `lib/site-content.ts`; update those in the same change. The assistant's knowledge base (`content/assistant/*.md`) answers about the same content and should be updated with it.
3. **Never overwrite a version.** Each round of changes ships as its own `release/rNN-<topic>` branch and `rNN` tag. No force pushes. Production is whatever `main` points to; tag it before promoting a new version.
4. **Document the version.** Update the "Current version" section of `README.md` and add an entry to `CHANGELOG.md` with what was implemented.
5. **Public repository.** No secrets, `.env` files or internal notes in commits.

## Where the content lives

- `lib/site-content.ts`: identity, home frames, navigation, timeline entries.
- `lib/work-videos.ts`: every video shown in the work pages and the timeline.
- `lib/agents.ts`: builds `/agents.md` and `/agents.txt`.
- `content/assistant/*.md`: knowledge base of the assistant (CLIPPY.EXE).
- `translations/index.ts`: shared UI strings.

## Checks before finishing

- `npm run typecheck` and `npm run build`.
- Files saved as UTF-8 without BOM, with real accented characters.
